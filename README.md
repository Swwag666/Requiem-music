Аудиоплеер на WPF: mp3 и wav, плейлисты в базе SQLite, история прослушиваний и счётчики — всё локально, без интернета, аккаунтов и лишних кнопок. Курсовой проект: свой винамп, только попроще и в одном окне.

> Играет, пока не скажешь «стоп».

ТЗ проекта по ГОСТ 19.201-78 — [ТЗ.txt](ТЗ.txt).
Проектная документация по ГОСТ 19.404-79 — [проектная-документация.md](проектная-документация.md).

## Возможности

### Воспроизведение
- Открытие одного файла или нескольких сразу (диалог с мультивыбором)
- Play / пауза / стоп
- Перемотка: ползунок можно тянуть и кликать в любое место полосы прогресса
- Текущее и общее время трека (`1:23 / 3:45`)
- Громкость слайдером + кнопка mute
- Форматы: **mp3, wav**

### Плейлисты
- Таблица треков: номер, название, исполнитель, длительность, прослушиваний
- Добавление файлов и целой папки — с рекурсивным поиском музыки в подпапках (удобно, когда всё разложено по альбомам)
- Удаление трека, очистка списка, перемещение треков вверх/вниз
- Двойной клик по треку — играет этот трек
- Именованные плейлисты в базе: создание, переименование, удаление, выбор из боковой панели
- Состав и порядок треков сохраняются в базу автоматически при каждом изменении — после перезапуска всё на месте, последний плейлист открывается сам

### Счётчики прослушиваний
- Каждый запуск трека увеличивает его счётчик в базе
- Счётчик виден колонкой в таблице плейлиста

### История воспроизведения
- Каждый запуск трека пишется в базу: трек + дата и время
- Окно истории — последние воспроизведения в обратном порядке, кнопка очистки

### Переключение треков
- Следующий / предыдущий
- Автопереход на следующий трек, когда текущий доиграл
- Повтор: один трек / весь список / выкл
- Shuffle — перемешивание
- Последний трек кончился — стоп, или по кругу, если включён повтор списка

### Теги и инфа о треке
- Чтение ID3-тегов (название, исполнитель, альбом) через **TagLib#**
- Нет тегов или в них каша — показывается имя файла без расширения
- Свойства трека: теги, путь к файлу, размер

### Поиск
- Строка над плейлистом, фильтрация по ходу набора
- Ищет по названию и исполнителю

### Устойчивость
- Битый или не-mp3 файл в списке не роняет плеер: ошибка показывается, играет следующий
- Файл из плейлиста в базе не найден — трек помечается серым, плеер спрашивает: удалить или пропустить
- База повреждена — плеер скажет об этом и создаст новую пустую
- Русские названия и пробелы в путях работают — это отдельная боль, проверено отдельно

## Технологии

| Что | Чем |
|---|---|
| Язык / UI | C# 12, WPF (.NET 8) |
| Архитектура | MVVM: ViewModel'ы плеера, плейлиста и истории; трек, плейлист и запись истории — отдельные модели |
| Звук | NAudio (WaveOutEvent + ридеры mp3/wav) |
| Теги | TagLib# |
| База данных | SQLite через Entity Framework Core (Microsoft.EntityFrameworkCore.Sqlite) |

## Сборка и запуск

Нужны Windows и [.NET SDK 8](https://dotnet.microsoft.com/download/dotnet/8.0).

Из консоли, из папки проекта:

```bash
dotnet run
```

Или открыть проект в Visual Studio 2022 и запустить (**F5**).

## Как пользоваться

1. Добавь файлы (`Файлы`) или папку целиком (`Папка`) — кнопки у плейлиста
2. Двойной клик по треку — играет
3. Полоса внизу — перемотка: кликни в любое место или потяни ползунок
4. Слайдер — громкость, динамик — mute
5. Строка сверху — поиск по плейлисту по ходу набора
6. Плейлисты — в боковой панели: создай, переключай, переименовывай; состав сохраняется сам
7. История — кнопка на панели: кто, когда и сколько раз слушал

## База данных

SQLite, один файл `requiem.db` рядом с программой, создаётся при первом запуске. Перенос на другой комп — просто скопировать файл.

| Таблица | Что хранит |
|---|---|
| `Track` | треки: путь, название, исполнитель, альбом, длительность, счётчик прослушиваний |
| `Playlist` | именованные плейлисты |
| `PlaylistTrack` | состав плейлистов: плейлист, трек, порядковый номер |
| `PlayEvent` | история: трек, дата и время запуска |

Схема и связи — в [проектной-документация.md](проектная-документация.md), раздел 3.3.

## Чего тут нет (и не планируется)

- Стриминг и радио из интернета
- Видео
- Эквалайзер
- Скины и темы
- Редактор тегов — теги только читаются
- Перетаскивание треков мышью — перемещение кнопками
- Визуализация, горячие клавиши, мини-режим
- Многопользовательский доступ

## Как проверять

- Открыл 3 трека, двойной клик по второму — играет второй, счётчик у него вырос на единицу
- Пауза/стоп/плей жать как попало — прога не падает
- Перемотал в конец — сам перешёл на следующий трек
- Громкость в ноль / mute — играет, но тихо
- Создал плейлист, накидал треков, перезапустил прогу — плейлист, порядок и счётчики на месте
- Папка с подпапками добавилась со всеми треками
- Битый файл в списке — не падает, пишет ошибку, играет следующий
- Трек с русским названием и пробелами в пути — играет
- Открыл историю — записи с датой и временем на месте; очистил — пусто
